# Zibal Advanced Connection Checker

یک افزونه وردپرس برای تشخیص و عیب‌یابی اتصال به درگاه پرداخت زیبال.

---

## امکانات

- **تست اتصال به سرور ایران** — بررسی دسترسی به `gateway.zibal.ir`
- **تست اتصال به سرور خارج** — بررسی دسترسی به `gateway.zibal.io`
- **نمایش IP خروجی سرور** — نشان دادن IP عمومی که زیبال می‌بیند
- **بررسی وضعیت IP** — تشخیص اینکه آیا IP سرور توسط زیبال مسدود است یا نه
- **تست مرچنت کد** — اعتبارسنجی مرچنت کد از طریق API زیبال
- **تست کامل یکجا** — اجرای همه تست‌ها با یک کلیک
- **تست‌های جداگانه AJAX** — اجرای هر تست به صورت مستقل بدون reload صفحه

---

## نصب

1. فایل‌های افزونه را در مسیر `wp-content/plugins/zibal-connection-checker/` قرار دهید
2. از پنل مدیریت وردپرس، افزونه را فعال کنید
3. از منوی سمت چپ، روی **Zibal Check** کلیک کنید

---

## نحوه استفاده

### تست کامل
مرچنت کد خود را در فیلد مربوطه وارد کرده و روی **Run Full Diagnostic** کلیک کنید.

### تست‌های جداگانه
هر بخش دارای دکمه **Test** مستقل است که بدون نیاز به reload صفحه نتیجه را نمایش می‌دهد.
